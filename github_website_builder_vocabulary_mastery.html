Step-by-Step Tutorial

如何使用 GitHub Pages 免費建置個人網站

邊學 GitHub 開發語法與專有名詞，邊打造專屬於你的第一個上線網站！

1

建立儲存庫 (Create a Repository) Step 1

登入 GitHub 後，點選右上角 + 按鈕選擇 New repository。

Repository (Repo): 專案儲存庫 Public: 公開 (Pages 免費版需設為 Public) Initialize: 初始化
💡 建議 Repository Name 命名為：your-username.github.io (將 your-username 換成你的 GitHub 帳號)
2

上傳網站程式碼 (Push Your Code) Step 2

準備你的 index.html 檔案，並使用 Git 指令將檔案推送到 GitHub 上。

# 1. 初始化 Git 專案 (Initialize Git)

git init

# 2. 加入所有檔案到暫存區 (Stage files)

git add .

# 3. 提交變更並加上訊息 (Commit changes with message)

git commit -m "Initial commit for website"

# 4. 推送到 GitHub 遠端儲存庫 (Push to remote repository)

git push -u origin main

3

開啟 GitHub Pages 功能 (Enable GitHub Pages) Step 3

進入 Repo 的 Settings ➔ 點選左側選單的 Pages ➔ 選擇分支發佈。

Source 設定： 選擇 Deploy from a branch
Branch 設定： 選擇 main 或 gh-pages / /(root) 並按下 Save
4

部署完成與網址存取 (Deployment & Live Site) Success

靜待 1~3 分鐘後，GitHub Actions 自動部署完畢，你的網站即順利上線！

URL: https://username.github.io/repository-name
